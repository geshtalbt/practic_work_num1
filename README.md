### 8. Итоговый проект: Симулятор межпланетной миссии «АРЕС-1»

* **Папка:** [`final_task8/`](https://github.com/geshtalbt/practic_work_num1/tree/main/final_task8)
* **Описание:** Полноценный консольный симулятор полета космического корабля к Марсу.
  * Использует физические расчеты (формула Циолковского, расчет времени разгона/торможения).
  * Реализует случайные события в пути с помощью планировщика `sched`.
  * Поддерживает параллельный запуск флота в независимых потоках (`threading`) и сохранение хроники в CSV.
  * Настроен для установки в качестве консольной команды `ares` через `pyproject.toml`.
